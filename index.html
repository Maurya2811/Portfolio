01. About

I'm a backend engineer at Addverb Australia. I build and run the software behind automated warehouses: order orchestration, allocation, hardware adapters, operator tools and the messaging that connects 20+ services. It runs 24/7, and when it breaks, real orders stop.

I like problems where the answer depends on measuring the system, not guessing. My best results came from making a distributed system observable first (correlated events, dwell time per stage) and only then changing the logic that was actually the bottleneck.

I'm looking for backend, platform or forward-deployed engineering roles working on distributed systems, event-driven architecture or AI-assisted tooling, at product companies where reliability and latency matter.
